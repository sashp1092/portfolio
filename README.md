# Портфолио — сайты для малого бизнеса

Демо-лендинги на Vite + React + Tailwind CSS v4. Тексты и цвета под нового клиента меняются в одном файле `data.js`.

| Проект | Что показывает | Демо |
|---|---|---|
| [Ясно Ремонт](projects/remont) | Лендинг под рекламу: квиз-калькулятор стоимости, заявки приходят в Telegram | [remont-livid.vercel.app](https://remont-livid.vercel.app) |
| [Noir & Blade](projects/noir-blade) | Лендинг-визитка барбершопа: услуги, галерея, мастера, запись | [noir-blade-six.vercel.app](https://noir-blade-six.vercel.app) |

Компании и контакты вымышленные, отзывы — явные заглушки.

## Запуск любого проекта
```bash
cd projects/<имя>
npm install
npm run dev
```
