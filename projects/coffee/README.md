# Пенка — кофейня с меню и заказом на самовывоз

Демо для портфолио: меню с корзиной, выбор объёма и молока, время самовывоза, заказ приходит в Telegram.
Vite + React (JavaScript) + Tailwind CSS v4 + lucide-react.

## Запуск
```bash
npm install
npm run dev     # http://localhost:5173 — отправка заказа имитируется
npm run build
```

## Как устроено
- `src/data.js` — весь контент: меню с ценами, тексты, контакты. Под нового клиента меняется он и цвета в `src/index.css`.
- `src/menu.js` — расчёт цен. Общий для сайта и сервера, поэтому сумма в Telegram всегда считается по меню, а не берётся из браузера.
- `src/useCart.js` — корзина, сохраняется в localStorage.
- `src/components/` — по компоненту на секцию; корзина: `CartBar` → `CartDrawer` → `Checkout`.
- `api/order.js` — серверная функция Vercel: проверяет заказ, пересчитывает цены и отправляет в Telegram.

## Заказы в Telegram
В Vercel → Settings → Environments → Production → Environment Variables:
- `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather
- `TELEGRAM_CHAT_ID` — id чата для заказов

Без них — демо-режим: гость видит «Заказ принят», но сообщение не отправляется.

## Перед сдачей клиенту
- Реальное меню и фото кофейни вместо Unsplash, настоящие отзывы вместо заглушек.
