# Нюанс — салон красоты с онлайн-записью

Демо для портфолио: прайс по категориям, мастера, работы и онлайн-запись в 4 шага
(услуга → мастер → дата и время → контакты). Запись приходит администратору в Telegram.
Vite + React (JavaScript) + Tailwind CSS v4 + lucide-react.

## Запуск
```bash
npm install
npm run dev     # http://localhost:5173 — отправка записи имитируется
npm run build
```

## Как устроено
- `src/data.js` — весь контент: услуги с ценами и длительностью, мастера, тексты, контакты, настройки записи.
- `src/booking.js` — логика записи: дни, свободные окна с учётом длительности услуги. Общая для сайта и сервера.
- `src/components/BookingModal.jsx` — окно записи; `DateTimePicker.jsx` — дни и время; `BookingForm.jsx` — контакты.
- `api/booking.js` — серверная функция Vercel: перепроверяет услугу, мастера и время и отправляет запись в Telegram.

## Запись в Telegram
В Vercel → Settings → Environments → Production → Environment Variables:
- `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather
- `TELEGRAM_CHAT_ID` — id чата администратора

Без них — демо-режим: гостья видит «Вы записаны!», но сообщение не отправляется.

## Важно про расписание
В демо занятость мастеров **условная** (`isBusy` в `src/booking.js`). Для клиента два варианта:
1. **У салона уже есть YCLIENTS или DIKIDI** — вставить ссылку на их виджет в `data.booking.externalUrl`.
   Все кнопки «Записаться» откроют его, а реальное расписание ведётся там.
2. **Нет системы записи** — убрать условную занятость (показывать все окна в рабочие часы),
   а администратор подтверждает каждую запись вручную. Сообщение в Telegram так и заканчивается: «Подтвердите запись клиенту».

## Перед сдачей клиенту
- Свои фото салона и работ мастеров (с их согласия), реальные цены, настоящие отзывы вместо заглушек.
- Политика конфиденциальности с реквизитами владельца; уведомление в Роскомнадзор подаёт владелец (152-ФЗ).
