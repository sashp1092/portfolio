# Ясно Ремонт — лендинг ремонта квартир с квизом

Демо для портфолио: лендинг под рекламу с квизом-калькулятором и отправкой заявок в Telegram.
Vite + React (JavaScript) + Tailwind CSS v4 + lucide-react. Дизайн — черновик из v0, перенесён в этот стек.

## Запуск
```bash
npm install
npm run dev     # http://localhost:5173 — отправка заявки имитируется
npm run build
```

## Как устроено
- `src/data.js` — весь контент: тексты, шаги квиза, цены, работы, контакты. Под нового клиента меняется он и цвета в `src/index.css`.
- `src/components/` — по компоненту на секцию. Квиз: `Quiz.jsx` → `OptionCard.jsx` → `ResultForm.jsx`.
- `api/lead.js` — серверная функция Vercel: принимает заявку и отправляет её в Telegram.

## Заявки в Telegram
В Vercel → Settings → Environment Variables добавить:
- `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather
- `TELEGRAM_CHAT_ID` — id чата, куда приходят заявки

Без этих переменных форма работает в демо-режиме: показывает «Заявка принята», но ничего не отправляет.
Токен — только в переменных Vercel, никогда в коде и Git.
